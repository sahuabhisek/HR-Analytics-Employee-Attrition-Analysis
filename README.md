**HR Analytics – Employee Attrition Analysis**

**Tools:** PostgreSQL, SQL, Excel

**Project Description:**

Developed an HR Analytics project using a dataset of 14,999 employee records to analyze employee attrition, satisfaction levels, salary distribution, department performance, and working hours.

**Key Responsibilities:**
- Imported and analyzed HR employee data using PostgreSQL.
- Performed department-wise employee and attrition analysis.
- Calculated employee attrition rates using aggregate functions.
- Analyzed salary categories and employee satisfaction.
- Used SQL Joins, Subqueries, CTEs, CASE WHEN, and Window Functions.
- Ranked departments based on employee count and attrition rates.
- Created rule-based employee attrition risk categories to support HR decision-making.

**Key Skills:** SQL, PostgreSQL, Data Analysis, Data Cleaning, Business Insights, Window Functions.
